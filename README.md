# Scrap Shift

Плагин-кампания в духе Lethal Company для **Minecraft Java 1.21.11** (Paper/Purpur).
Шатл, вылазки на планеты, процедурные заводы, квота, скупщик и собственный ресурспак.

## Требования

- Minecraft Java 1.21.11, сервер Paper или Purpur
- Клиент принимает серверный ресурспак (плагин выдаёт его автоматически)

## Установка

1. Положить `ScrapShift-<версия>.jar` из архива обновления в папку `plugins/`.
2. Перезапустить сервер. Плагин сам создаст мир `scrap_shift`, лобби и шатл.
3. Игроки при входе получают ресурспак и попадают в шатл.

## Обновление

Архив `ScrapShift-<версия>-update.zip` содержит только JAR. Заменить старый JAR в `plugins/` и перезапустить сервер.
Если в описании обновления указано «ресурспак обновлён», он переустановится сам при входе.

## Управление

- Кнопка на шатле — запуск вылазки; рычаг — возврат на корабль.
- Панель настроек на стене шатла (квота, множитель, дни, здоровье мобов) доступна только до первого запуска.
- Горячий слот фонарика — отдельная пятая ячейка, включается по ПКМ и гаснет при смене слота.
- Административные команды: `/scrap`, `/scrap quota|multiquota|daylimit|mobhealth|skip`, `/scrap settings`, `/scrap give`.

## Сборка из исходников

```
mkdir -p build/classes build/lib
# зависимости: JDK 21, JOML, Gson и библиотеки Paper/Purpur
javac -proc:none -encoding UTF-8 -cp "build/lib/*" -d build/classes source/ScrapShift.java source/Scenery.java source/PackService.java
```

Ресурспак собирается скриптом `source/make_pack.py`, модели MirRP подтягиваются `imports_creatures.py`/`merge_toon.py`.

## Структура

- `source/` — исходники плагина, скрипты сборки пака, конфиги
- `Обновление-*.md` — журнал изменений по версиям
- `Установка.md` — краткая инструкция для игроков

В репозитории нет сторонних карт из `imports/`, локальной сборки и старых архивов начиная с 3.0.
